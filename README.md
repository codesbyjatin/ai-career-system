# 🚀 AI Career Intelligence System

An AI-powered system that analyzes resumes, calculates ATS scores, and provides career insights.

---

## 🔥 Features
- 📄 Resume parsing (PDF)
- 🧠 Skill extraction
- 📊 ATS score calculation
- 🎯 Job matching
- ❌ Missing skill detection

---

## 🛠 Tech Stack
- Python
- Streamlit
- MySQL
- spaCy

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
